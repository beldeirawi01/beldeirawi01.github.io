Page objects keep tests stable

Locators and actions live in page objects. Tests hold the assertions. Pick a page object, then change the UI.

// LoginPage.ts (illustrative pattern)
readonly loginButton = page.locator(
  '[data-test="login-button"]'
);
 
// login.spec.ts
await loginPage.login(user, password);
await expect(inventoryPage.title).toBeVisible();

The login button’s locator is unchanged.

0 files to fix

Custom fixtures (test.extend) hand every spec a logged-in session and pre-built page objects. Data files hold credentials and customer edge cases.
